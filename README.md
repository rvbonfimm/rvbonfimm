### 👋 About Me

Software Engineer focused on building **resilient backend services, scalable APIs, and distributed architectures**. I value clean code, pragmatic engineering, and operational simplicity—taking products from architecture and development to containerized deployment and observability.

- 🔭 **Current focus:** System integration connectors, data pipelines, event-driven architectures, and multi-tenant SaaS platforms.
- ⚙️ **Core mindset:** Clean Architecture, SOLID principles, automated testing, and reliable infrastructure.
- 🌱 **Exploring:** Cloud-native patterns on GCP/AWS, high-throughput messaging, and edge/offline-first applications.
